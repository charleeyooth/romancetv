# RomanceTV

### Romance-Focused Streaming & Shared Viewing Experience

RomanceTV is a romance-focused streaming product that combines content discovery with shared viewing experiences designed for couples and people connecting remotely.

This repository is a **public portfolio showcase**. Private source code, credentials, APIs, and production configuration are not published here.

## Product Concept

The application combines streaming with social viewing features so people can watch together rather than experience content only as individual viewers.

## Date Rooms

A central experience is the **Date Room**, where users can create a shared viewing room around a movie or show.

Product work includes:

- creating Date Rooms
- selecting a title
- choosing a scheduled viewing time
- shared room experiences
- synchronized social viewing concepts
- mobile-first interaction patterns
